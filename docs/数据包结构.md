---

# 🧠 1. 核心设计理念（先理解这个）

你系统里只有一类东西：

> 👉 “一次真实发生的 Web 行为”

不管是点击 / 请求 / 返回 / websocket，都统一成 Event。

---

# ⭐ 2. 完整 Event JSON（核心结构）

```
{  "event_id": "evt_001",  "timestamp": 1710000000,  "source": {    "url": "https://target.com/login",    "page_path": "/login",    "page_title": "Login Page"  },  "actor": {    "role": "guest",    "session_id": "sess_abc123"  },  "action": {    "type": "api_call",    "trigger": "click_submit_button",    "ui_element": {      "tag": "button",      "text": "Login"    }  },  "request": {    "method": "POST",    "url": "/api/login",    "headers": {      "content-type": "application/json"    },    "params": {},    "body": {      "username": "test",      "password": "123456"    }  },  "response": {    "status": 200,    "body": {      "token": "eyJhbGci...",      "user_id": 1001    }  },  "state_before": {    "auth": "guest",    "user_id": null,    "permissions": []  },  "state_after": {    "auth": "logged_in",    "user_id": 1001,    "permissions": ["user"]  },  "resource_changes": [    {      "type": "session",      "change": "created",      "key": "auth_token"    }  ],  "dependencies": {    "requires": [],    "produces": ["auth_token"]  },  "tags": [    "auth",    "login",    "state_change"  ]}
```

---

# 🧠 3. 这个结构每一块的意义（很关键）

---

## ① actor（谁在操作）

```
"role": "guest"
```

👉 用来做：

- 权限分析
- 越权检测

---

## ② action（行为来源）

```
"trigger": "click_submit_button"
```

👉 用来做：

- UI → API 关联
- 自动探索行为建模

---

## ③ request / response（网络层）

👉 你抓包的核心数据

---

## ④ state_before / state_after（核心）

```
guest → logged_in
```

👉 用来做：

- 状态机
- 逻辑漏洞检测
- 流程推理

---

## ⑤ resource_changes（资源变化）

```
session createdorder createdbalance updated
```

👉 用来做：

- 业务建模
- 数据流分析

---

## ⑥ dependencies（非常重要）

```
requires: auth_tokenproduces: auth_token
```

👉 用来做：

- API链路图
- 自动攻击路径生成

---

## ⑦ tags（AI用）

```
"auth", "login", "state_change"
```

👉 用来：

- LLM分类
- 检索
- RAG

---

# 🧠 4. 多事件组合后会变成什么？

---

## login

```
guest → logged_in
```

---

## order

```
logged_in → has_order
```

---

## pay

```
has_order → paid
```

---

👉 自动形成：

```
state_machine = {  "guest": ["logged_in"],  "logged_in": ["has_order"],  "has_order": ["paid"]}
```

```

```

- login → order → pay
